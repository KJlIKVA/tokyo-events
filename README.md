# Tokyo Events

Бот сам ищет новые события в Токио и анонсы концертов любимых артистов и сразу присылает их в Telegram.
Работает бесплатно на GitHub Actions (публичный репозиторий) каждые 2 часа с 7:00 до 23:00 по Токио.

## Ранги

| | Что это | Пример |
|---|---|---|
| 🟢 | обычное событие в Токио (приходит без звука) | открытие нового парка, фестиваль, мацури, иллюминация |
| 🟠 | интереснее обычного, в Токио | временная выставка Ван Гога в музее, первое в Японии большое шоу |
| 🟣 | самое важное — где угодно в Японии | Экспо и другие грандиозные события; **концерты моих артистов** |

Мои артисты: **Ado, YOASOBI, RADWIMPS, 美波 (Minami), ヨルシカ (Yorushika)**.
美波 — певица с «カワキヲアメク» (сайт 373official.com). Модели прямо сказано не путать её с актрисой 美波
и другими Минами (佐藤美波 и т.п.), а концерт любимого артиста кодом всегда ставится в 🟣.

Пример уведомления (настоящий, из тестового прогона 13.10.2026):

```
🟠 Выставка Музея искусств Цинциннати: «Сокровища Европы, попавшие в Америку»
📅 10 октября 2026 – 10 января 2027
💴 взрослые 2 400 ¥, старшеклассники и студенты 1 500 ¥, школьники 800 ¥
🗺 上野の森美術館 (Ueno Royal Museum)          ← ссылка на Google Maps
🌐 Официальный сайт                             ← из статьи; нет — 🏛 сайт площадки

84 работы из Cincinnati Art Museum, среди главных — поздний Ван Гог «Двое в тополиной роще».

#выставка
```

Правила:
- **Даты обязательны.** Для временного события — с какого по какое, для открытия — когда открывается.
  Если известен только год («в 2027 году»), уведомления не будет: оно придёт, когда объявят хотя бы примерные даты.
- **Цена** — сразу в уведомлении; если вход бесплатный, так и написано; если ещё не объявлена — «Цена пока не объявлена».
- **Место** — 🗺 ссылка на Google Maps, если это конкретное место (музей, парк, зал, стадион); линия поезда,
  целый город или несколько мест — 📍 просто текстом. Для тура — все площадки с датами.
- **Ссылка** (находит код, без ИИ; страница должна открываться): 🌐 официальный сайт события из статьи →
  иначе 🏛 сайт площадки (Wikidata) → иначе 🔗 «Подробнее» — сама статья.
- Цена и даты — только если они есть в статье: модель ничего не придумывает.
- **Повторы**: все отправленные события лежат в базе (`state/events.db`, SQLite). Новость о событии, которое уже
  есть в базе, без изменений не присылается — сколько бы СМИ о нём ни написали.
- **🔴 Обновления**: если в новости о событии из базы есть новое, код сверяет поля с базой и присылает красное
  «🔴 Обновление» со списком «Что изменилось»: объявлены / изменились / уточнились даты, объявлена или изменилась
  цена, вход стал бесплатным, сменилась или добавилась площадка, перенос, отмена. Пустое поле в новой статье —
  не изменение (её просто не упомянули). Обновления приходят со звуком, история хранится в базе.

## Скидки для поездок

Отдельно бот следит за скидками — **от 10%**, цвет по размеру: 🟢 10–29%, 🟠 30–49%, 🟣 от 50%.

- **Отели и рёканы — по реальным ценам** (`hotels.py`, API 楽天トラベル, без ИИ). Трижды в день (9:00, 15:00
  и 19:00 по Токио) бот берёт цены в ~58 местах по всей Японии (`config.yaml → hotels.areas`: онсэны от Хоккайдо
  до Кюсю, Киото, Осака, Окинава) для вариантов заезда: **пятница на 1 ночь, суббота на 1 ночь, пятница–воскресенье
  и день в день**; 2 взрослых, в онсэн-местах — с ужином и завтраком. Цену на ближайшие 2 недели (и на сегодня)
  сравнивает с обычной ценой того же отеля в тот же день недели на другие недели и с прошлыми ценами на ту же дату.
  Пример: обычно 35 000 ¥, на эти выходные 10 000 ¥ → 🟣 ♨️ −71%. Экономия от 3 000 ¥, рейтинг от 3.5;
  «сегодня» приходит со звуком и первым; стало ещё дешевле — 🔴 «Ещё дешевле».
  Нужны бесплатные ключи Rakuten: `uv run tokyo-events setup-rakuten` (там же — что указать в приложении:
  с 2026 года Rakuten требует «разрешённый сайт», бот отправляет запросы от имени `kjlikva.github.io`).
- **Авиабилеты — по реальным ценам Google Flights** (`flights.py`, через SerpApi). Раз в день (9:00) Google
  Flights Explore находит самую низкую цену туда и обратно из Токио (Ханэда, Нарита) по каждому направлению на
  полгода вперёд: выходные по Японии и неделя до 7 часов лёта. Бот запоминает цены и сравнивает с обычной
  ценой направления (медиана за прошлые дни; первые 4 дня только запоминает). Лучшие находки проверяет обычным
  поиском Google Flights на те же даты: если Google считает цену высокой — не присылает, иначе показывает
  обычный диапазон. Пример: Саппоро обычно 20 000 ¥, на выходные 9 800 ¥ → 🟣 ✈️ −51%.
- **Booking.com, Trip.com, Agoda и др. — через Google Hotels** (`google_hotels.py`, SerpApi). У Booking.com и
  Trip.com открытого API цен нет (только для партнёров по договору), а Google Hotels показывает цены всех сайтов
  бронирования и сам помечает «на N% ниже обычного» (ниже медианы цены отеля за год, от 15%). 14 популярных мест
  (`config.yaml → google_hotels.areas`) на ближайшие 2 субботы — по кругу, на сколько хватит запросов.
  В уведомлении — цены по сайтам: «Trip.com 12 000 ¥ · Booking.com 12 900 ¥ · Agoda 13 400 ¥».
  Нужен ключ SerpApi: `uv run tokyo-events setup-serpapi`. Бесплатно — 250 запросов в месяц: бот тратит не больше
  1/30 в день (~8: 2–4 на авиабилеты, остальное на отели). Купили тариф больше — `serpapi.monthly_searches`.
- **Синкансэн, паромы, распродажи авиакомпаний и сайтов бронирования, достопримечательности, региональные
  скидки** — по новостям (как события): えきねっと トクだ値, EX早特, «半額», さんふらわあ, 東海汽船, Peach,
  ジェットスター, JAL/ANA タイムセール, Booking.com, Trip.com, じゃらん, 一休 タイムセール, бесплатный вход и т.п.
  У JR и паромных компаний нет открытых цен, поэтому синкансэн и паромы — только по объявленным акциям.

## Как это работает

1. **Сбор** (`sources.py`): официальные сайты артистов (RSS 美波, страницы новостей RADWIMPS и ヨルシカ),
   музыкальные новости natalie.mu (через Google Новости: напрямую сайт не пускает серверы GitHub), поиск Google Новостей по Токио (выставки, открытия, фестивали) и по
   грандиозным событиям Японии, Tokyo Cheapo. Список — в `config.yaml`, раздел `sources`.
2. **Отсев без модели** (`pipeline.py`): уже виденное, старше 72 часов, повторы одной статьи под разными
   ссылками, в общих музыкальных лентах — всё, где не упомянут никто из артистов.
3. **Отбор моделью** (`classify.py`, промпт `prompts/classify.txt`): по заголовкам — событие или нет, ранг,
   дубль или обновление уже отправленного. Модель видит список отправленного за 45 дней, поэтому один и тот же
   тур из пяти СМИ придёт один раз.
4. **Подробности** (`article.py`, `enrich.py`, `venue.py`, промпт `prompts/enrich.txt`):
   - код сам скачивает статью (ссылку Google Новостей раскрывает в настоящий адрес) и достаёт её текст;
   - модель только читает этот текст и пишет название, даты, цену, место и описание — **в интернете она не ищет**
     (это дорого, и такой возможности в коде нет вообще);
   - ссылки находит код, без ИИ: официальный сайт — по подписи «公式サイト / 特設サイト» в статье, иначе сайт
     площадки из Wikidata, иначе ссылка на саму статью; Google Maps — по названию места.
   Нет чётких дат — уведомление не отправляется.
5. **Telegram** (`telegram.py`): каждое событие — отдельное сообщение на все подключённые аккаунты, сразу как найдено.
6. **База событий** (`events_db.py`, `state/events.db`): отправленные события с датами, ценой, площадками, ссылками,
   все статьи о каждом и история изменений. По ней — поиск повторов и 🔴 обновлений.
7. **Память** (`state.py`, `state/state.json`): какие ссылки уже видели, расход токенов.
   Оба файла живут в ветке `state` репозитория (`scripts/state.sh`).

Если что-то сломалось — придёт сообщение «⚠️ Tokyo Events: … с ошибкой» со ссылкой на запуск.

## Настройка (один раз)

1. **Бот**: в Telegram напишите [@BotFather](https://t.me/BotFather) → `/newbot` → получите токен.
   Откройте своего бота и нажмите Start (иначе он не сможет вам писать).
2. **Подключить**: `uv run tokyo-events setup-telegram` — спросит токен (ввод скрыт) и chat id
   (Enter — найдёт сам), проверит, пришлёт тестовое сообщение и сохранит в `.env`.
   Можно подключить несколько аккаунтов: с каждого сначала нажмите Start у бота, потом введите его chat id
   (или «+» — найти автоматически). В `TELEGRAM_CHAT_ID` они хранятся через запятую.
3. **Свой ключ OpenAI**: `uv run tokyo-events setup-openai`. Команда покажет, как завести в OpenAI отдельный
   проект «Tokyo Events» с месячным бюджетом и ключом только для него, затем спросит ключ (ввод скрыт),
   проверит его пробным вызовом `gpt-5.6-terra`, сохранит в `.env` и предложит обновить секрет на GitHub.
4. **GitHub**: секреты `OPENAI_API_KEY`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` (Settings → Secrets and
   variables → Actions). Команды `setup-openai` и `setup-telegram` сами предлагают их обновить.
5. Actions → **check** → Run workflow: сначала с галочкой dry-run (посмотреть лог), потом без неё.

Первый запуск берёт только находки за последние 12 часов, чтобы не завалить старым.

## Локально

```bash
uv sync
cp .env.example .env              # и заполнить
uv run tokyo-events sources       # проверить источники (без модели и Telegram)
uv run tokyo-events setup-openai  # свой ключ OpenAI
uv run tokyo-events setup-telegram # бот и аккаунты
uv run tokyo-events setup-rakuten  # ключи 楽天トラベル для цен отелей
uv run tokyo-events setup-serpapi  # ключ SerpApi: авиабилеты и Booking/Trip.com через Google
uv run tokyo-events test-telegram # 3 тестовых уведомления 🟢🟠🟣
uv run tokyo-events run --dry-run # полный прогон: уведомления печатаются, а не отправляются
uv run tokyo-events events --github # база событий с GitHub: что отправлено и история 🔴 обновлений
uv run pytest -q                  # тесты
```

## Как поменять

- **Добавить артиста** — `config.yaml` → `artists` (имя, как его пишут в заголовках, кто это и с кем не путать)
  и при желании его официальный сайт в `sources`.
- **Добавить источник** — `config.yaml` → `sources`: `rss` (лента), `google_news` (запрос как в поиске),
  `page` (страница новостей без ленты + шаблон ссылок).
- **Без зелёных** — `filters.notify_ranks: [orange, purple]`. Со звуком для всех — `filters.silent_ranks: []`.
- **Чаще/реже** — cron в `.github/workflows/check.yml` (время по UTC, Токио = UTC+9).
- **Потолок расходов** — `config.yaml` → `llm.daily_token_limit` (жёсткий дневной лимит токенов).
  Модель — только `gpt-5.6-terra`: другие код откажется запускать (`ALLOWED_MODELS` в `config.py`).

## Расходы

GitHub Actions для публичного репозитория бесплатны. Модель `gpt-5.6-terra` (другие код запускать не даст),
без поиска в интернете:
- отбор: ≈ $0.002 за находку;
- подробности по тексту статьи: ≈ $0.01–0.02 за событие.

Прогон «с нуля» (55 находок, 10 событий) 13.10.2026 стоил $0.21; обычный запуск по расписанию — центы.
Rakuten и SerpApi (бесплатный тариф) — $0; бот сам не выходит за 250 запросов SerpApi в месяц.
Ориентир — $3–8 в месяц. Жёсткий потолок — `llm.daily_token_limit` (1 000 000 токенов в сутки).
Стоимость каждого вызова — в логах запуска.
